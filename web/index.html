How it works
Original JSON uses digit tests and a carry graph. Compact tally JSON uses standard contains counts and a small recursive adder. Neither encoding needs custom validator logic.
Deliberately bounded
The compiler supports sums and differences of nonnegative decimal strings and constants, in several equations or inequalities. Fields can be multiplied by whole numbers, such as 3 * price, but not by each other. No signed input amounts yet. The compact encoding changes the exported record format.
