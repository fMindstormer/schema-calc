How it works
Original JSON uses digit tests and a carry graph. Compact tally JSON uses standard contains counts and a small recursive adder. Neither encoding needs custom validator logic.
Deliberately bounded
The compiler supports sums and differences of nonnegative decimal strings, constants and multiple equalities. No multiplication, comparisons or signed input amounts yet. The compact encoding changes the exported record format.
